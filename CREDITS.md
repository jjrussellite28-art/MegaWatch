## Ideas, data and services

- **u/demon-myth**: the public "Watch Order" Stremio add-on. MegaWatch only asks it questions at run time; none of its code or data is bundled.
- **RobbdeezeNutz**: ideas for live sports, IPTV portals and direct-link streaming (a fork of Debrify). No code is copied.
- **TMDB**: "This product uses the TMDB API but is not endorsed or certified by TMDB."
- **Stremio Cinemeta**: movie and show details.
- **Trakt, Simkl, MDBList**: optional tracking services, used through their public APIs.

the Custom settings page, no analytics and no remote donation config.
